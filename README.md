# Mãos à Obra — Landing Page

Landing page institucional desenvolvida para a **Mãos à Obra Multi Serviços**, empresa de manutenção e reformas em Curitiba e região.

🔗 **Demo:** https://maosaobra-pink.vercel.app

## ✨ Funcionalidades

- Layout responsivo (mobile-first)
- Seções de serviços, diferenciais, processo, depoimentos, galeria e área de atuação
- CTAs de orçamento com integração ao WhatsApp e telefone
- Navegação por âncoras entre as seções

## 🛠️ Tecnologias

- HTML5
- CSS3
- Deploy na Vercel

## ▶️ Como rodar

```bash
git clone https://github.com/LucasM07-2001/maosaobra.git
cd maosaobra
# abra o index.html no navegador
```
